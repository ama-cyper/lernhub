So funktioniert’s

Wo liegen meine Reports?

Alle Lernreports und Bilder liegen im privaten GitHub-Repo lernhub-daten. Diese Seite ist nur die Bedienoberfläche. Sie enthält selbst keine Inhalte und lädt alles erst nach der Anmeldung mit deinem Schlüssel. Ohne Schlüssel bekommt man von GitHub nur „nicht gefunden“.

Neues Gerät einrichten

  1. Diese Seite öffnen (am Handy: Teilen → „Zum Home-Bildschirm“, dann wirkt sie wie eine App).
  2. Zugangsschlüssel aus dem Passwortmanager einfügen → Anmelden.
  3. Auf fremden Rechnern „Auf diesem Gerät merken“ abhaken und am Ende auf Abmelden tippen.
Schlüssel verloren oder abgelaufen? Auf GitHub → Fine-grained tokens den alten löschen und einen neuen erstellen: nur Repo lernhub-daten, Recht „Contents: Read and write“.

Bearbeiten und Speichern

  • „Bearbeiten“ öffnet den Editor. Er speichert automatisch ein paar Sekunden nach der letzten Änderung, und sofort, wenn du die App wechselst oder das Handy sperrst.
  • Jede Speicherung ist ein eigener Stand. Auf GitHub siehst du unter History jede Version und kannst jede wiederherstellen.
  • Ohne Internet bleibt deine Änderung als Entwurf auf dem Gerät. Beim nächsten Öffnen bietet der Editor an, sie wiederherzustellen.

Toggles (wie in Notion)

Beim Bearbeiten klappt nur das Dreieck auf und zu, ein Klick auf den Titel setzt den Cursor. Im Lesemodus klappt die ganze Zeile.

  • Neu: > + Leertaste am Zeilenanfang, /toggle oder Strg+Umschalt+7 (Mac: ⌘⌥7).
  • Enter im Titel: offen → neue erste Zeile im Toggle; zu → neuer Toggle darunter. Leerer Titel + Enter → wird normaler Text.
  • Umschalt+Enter: Zeilenumbruch im Titel.
  • Rücktaste am Titelanfang: Toggle wird normaler Text, der Inhalt bleibt darunter.
  • Rücktaste am Anfang der ersten Inhaltszeile: Zeile wandert in den Titel. … der letzten Zeile: Zeile rückt aus dem Toggle aus.
  • Tab / Umschalt+Tab: Zeile oder ganzen Toggle in den Toggle darüber schieben bzw. wieder herausholen.
  • Strg+Enter (Mac: ⌘Enter): Toggle auf/zu. Strg+Alt+T (Mac: ⌘⌥T): alle Toggles zu bzw. auf.
  • Strg+Z / Strg+Umschalt+Z / Strg+Y (Mac: ⌘Z, ⌘⇧Z): Rückgängig und Wiederholen, auch für alle Toggle-Umbauten.

Zeilen verschieben (wie in Notion)

  • Beim Bearbeiten mit der Maus über eine Zeile fahren → links erscheinen + und der Griff mit den sechs Punkten. Am Handy/iPad steht der Griff an der Zeile mit dem Cursor.
  • Griff ziehen: eine blasse Kopie folgt der Maus, die blaue Linie zeigt, wo die Zeile landet. Über einem Toggle-Titel (rechts, untere Hälfte) oder einem leeren Toggle wandert sie hinein. Esc bricht ab.
  • Griff klicken: Löschen (Entf), Duplizieren (Strg+D), Nach oben, Nach unten.
  • + klicken: neue Zeile darunter mit geöffnetem /-Menü (Alt-Klick: darüber).
  • Strg+Umschalt+↑/↓ (Mac: ⌘⇧↑/↓) verschiebt, Strg+D (Mac: ⌘D) dupliziert die Zeile mit dem Cursor.
  • Enter am Zeilenende ergibt immer eine einfache Textzeile, ohne Fett, Marker oder Stil der Zeile davor. Nach einer Bildunterschrift, Überschrift oder Hinweisbox steht sie darunter, nicht darin.

Zwei Geräte gleichzeitig

Wurde ein Report inzwischen auf einem anderen Gerät geändert, überschreibt der Editor nichts. Du bekommst die Wahl: Andere Version laden (deine Änderung bleibt als Entwurf erhalten) oder Meine Version speichern.

Neue Reports

„＋ Vorlesung“ → HTML-Datei wählen. Eingebettete Bilder werden automatisch als eigene Dateien abgelegt, damit der Report schnell lädt, auch am Handy.
