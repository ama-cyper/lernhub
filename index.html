Anmelden auf diesem Gerät

Deine Lernreports liegen in einem privaten GitHub-Repo. Zum Öffnen brauchst du einmal pro Gerät deinen persönlichen Zugangsschlüssel.

Neuen Schlüssel erstellen
  1. Öffne github.com → Fine-grained token.
  2. Expiration: z. B. 1 Jahr.
  3. Repository access: „Only select repositories“ → nur lernhub-daten.
  4. Permissions → Repository → Contents: „Read and write“. Sonst nichts.
  5. Erstellen, Schlüssel kopieren, hier einfügen — und im Passwortmanager sichern.
